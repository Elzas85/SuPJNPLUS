# SuPJN+ 1.3.4: revisión de la redacción

Fecha: 23 de septiembre de 2026
Versión anterior: 1.3.3 (del mismo día)
Banco de pruebas: 153 pruebas con resultado satisfactorio y 0 fallidas.
Analizador propio: 0 avisos.

Esta versión corrige únicamente textos, en la ventana y en el README. No
modifica ninguna función ni ningún dato guardado.

## 1. Textos con contenido incorrecto

- **Respaldo sin carpeta elegida.** Indicaba que el respaldo "tenés que hacerlo manualmente",
  cuando elegir la carpeta es precisamente lo que lo vuelve automático. Texto
  actual:
  "Elegí la carpeta donde se guarda el respaldo automático. Conviene que esté en la nube, por ejemplo OneDrive, para leerlo desde otra PC, y fuera de cualquier carpeta que se suba a GitHub."
- **"Guardando solo en…"** podía interpretarse como "únicamente en". Texto
  actual: "Se guarda automáticamente en…".
- **Acerca de, Dejar nota.** Indicaba "Pide confirmar antes de empezar", y desde
  la 0.6.0 no existe paso de confirmación: la solapa informa al ingresar y el
  botón inicia el lote.
- **Anotaciones y notas.** Tres textos describían las anotaciones como "notas",
  precisamente al explicar que no lo son. Ahora indican
  "privadas y de trabajo, y no se escriben en el expediente". El botón de
  exportar indica "registro de notas".

## 2. Vocabulario unificado

- **"Tanda" pasa a "lote"** en todos los textos de pantalla y en el README
  ("lote de notas", "Lote en curso", "Retomando el lote…"), con sus
  concordancias.
- Las causas son siempre **seleccionadas**; "elegidas" queda reservado para las
  actuaciones.
- Los errores del servidor se expresan siempre como **"respondió con error N"**;
  en el registro de fallas, como **"código HTTP"**.
- Se utiliza **PC** en lugar de "equipo" o "máquina".
- **"Nueva cédula electrónica"**, como la denomina el PJN, en la solapa
  Notificaciones.
- Filtro de la lista: **"Últ. act. desde … hasta …"**.
- Botones: **"Cerrar"** en lugar de "Listo" (contraseña) y
  **"Quitar de Descargas"** en lugar de "Descartar".
- "Paginado" pasa a **"paginador"**, como en la revisión del PJN.

## 3. Registro

Se eliminaron las siguientes expresiones coloquiales: "¡hay un aviso!",
"Sigo en", "dejó de dejar nota", "no le pone lápiz",
"le lee la hora a la firma", "no contesta con su almacén",
"no dice ser de esta cuenta", "aprieta el lápiz", "lo de dejar nota",
"tildado", "a mano", "no se sabe si hay algo o no", "cosas que cambiaron",
"es del PJN", "Seguí con Siguiente", "cuando se la sabe", "la app".
En el README: "le toca la sesión", "pisa", "sobran".

## 4. Gramática

- "Anotaciones privados" → "privadas".
- "estaba parada hace más de 3 minutos" → "estaba detenido desde hacía más de 3 minutos".
- README: "le espera con la lista abierta" → "la espera".
- "Hubo un problema con la carpeta elegida" → "No se pudo usar la carpeta elegida".

## 5. README

- Se reescribió la sección **"En el teléfono"**: la versión para Android es
  SuPJN Lite, un producto independiente que no se construye a partir de este
  script.
- **"Cómo se usa"**: el ingreso se realiza por el Portal del PJN, y la ventana se
  abre automáticamente y maximizada (indicaba "se inicia minimizado", lo que
  contradecía "Qué hace").
- La introducción menciona NOTATOMIC.
- El enlace de instalación usa `SuPJNPLUS`, del mismo modo que el encabezado del
  script.

## 6. Acciones necesarias

Instalar la 1.3.4 desde Google Drive y publicar el script y el README en GitHub.
